# six

Limit how many times setInterval fires.

[![codecov](https://codecov.io/gh/UltiRequiem/six/graph/badge.svg)](https://codecov.io/gh/UltiRequiem/six)

Limit the amount of times that `setInterval` will fire.

> Made for
> [this StackOverflow Question](https://stackoverflow.com/questions/2956966) 😆

## Install

```sh
npm install @ultirequiem/six
```

## Usage

ESM only, types included: the same import works in Node.js, Bun and browsers.
